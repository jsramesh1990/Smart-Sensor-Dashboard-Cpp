# Smart Sensor Dashboard (C++ Project)

This project demonstrates professional C++ practices for embedded systems, IoT applications, and data processing systems where memory efficiency, type safety, and clean architecture are critical requirements.

This project demonstrates the logical use of:
- struct
- enum
- union
- return
- typeof (GCC extension) / decltype (C++)

The program simulates a sensor dashboard that can handle
multiple types of sensor inputs using a union inside a struct.
